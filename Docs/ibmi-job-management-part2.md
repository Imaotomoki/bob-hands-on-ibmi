# IBM i ジョブ管理サービス（パート2）

このドキュメントは、IBM i のジョブキュー、スケジュールジョブ、サブシステムに関連するシステムサービスについて説明します。

## JOB_QUEUE_ENTRIES ビュー

JOB_QUEUE_ENTRIES ビューは、ジョブ待ち行列上のジョブに関する情報を返します。

**権限:** 不要。

**主要カラム:**

| カラム名 | システムカラム名 | データ型 | 説明 |
| --- | --- | --- | --- |
| JOB_QUEUE_STATUS | STATUS | VARCHAR(9) | ジョブ・キュー上のこのジョブの状況（HELD、RELEASED、SCHEDULED） |
| JOB_NAME | JOB_NAME | VARCHAR(28) | 修飾ジョブ名 |
| JOB_USER | JOB_USER | VARCHAR(10) | ジョブを開始したユーザー・プロファイル |
| JOB_NUMBER | JOB_NUMBER | VARCHAR(6) | ジョブのジョブ番号 |
| JOB_TYPE | JOB_TYPE | VARCHAR(3) | ジョブのタイプ |
| JOB_QUEUE_PRIORITY | JOBQ_PRI | INTEGER | ジョブ・キュー優先順位（0が最高、9が最低） |
| JOB_ENTERED_SYSTEM_TIME | ENTRY_TIME | TIMESTAMP(0) | ジョブがシステムに入れられたタイムスタンプ |
| JOB_SCHEDULED_TIME | JOB_SCHEDT | TIMESTAMP(0) | ジョブのスケジュール時刻 |
| SUBMITTER_JOB_NAME | SBMJOBNAME | VARCHAR(28) | 投入者ジョブの修飾ジョブ名 |

### 使用例

```sql
-- すべてのジョブ待ち行列エントリーを表示
SELECT * FROM QSYS2.JOB_QUEUE_ENTRIES;

-- 特定のジョブキューのエントリーを表示
SELECT JOB_NAME, JOB_USER, JOB_QUEUE_STATUS, JOB_QUEUE_PRIORITY
FROM QSYS2.JOB_QUEUE_ENTRIES
WHERE JOB_QUEUE_NAME = 'QBATCH' AND JOB_QUEUE_LIBRARY = 'QGPL'
ORDER BY JOB_QUEUE_PRIORITY, JOB_ENTERED_SYSTEM_TIME;

-- 保留中のジョブを表示
SELECT JOB_NAME, JOB_USER, JOB_QUEUE_NAME, JOB_ENTERED_SYSTEM_TIME
FROM QSYS2.JOB_QUEUE_ENTRIES
WHERE JOB_QUEUE_STATUS = 'HELD'
ORDER BY JOB_ENTERED_SYSTEM_TIME;

-- スケジュールされたジョブを表示
SELECT JOB_NAME, JOB_USER, JOB_SCHEDULED_TIME, JOB_QUEUE_NAME
FROM QSYS2.JOB_QUEUE_ENTRIES
WHERE JOB_QUEUE_STATUS = 'SCHEDULED'
ORDER BY JOB_SCHEDULED_TIME;

-- 長時間待機しているジョブを特定
SELECT JOB_NAME, JOB_USER, JOB_QUEUE_NAME,
       JOB_ENTERED_SYSTEM_TIME,
       TIMESTAMPDIFF(8, CHAR(CURRENT_TIMESTAMP - JOB_ENTERED_SYSTEM_TIME)) AS WAIT_HOURS
FROM QSYS2.JOB_QUEUE_ENTRIES
WHERE JOB_QUEUE_STATUS = 'RELEASED'
  AND TIMESTAMPDIFF(8, CHAR(CURRENT_TIMESTAMP - JOB_ENTERED_SYSTEM_TIME)) > 1
ORDER BY WAIT_HOURS DESC;
```

## JOB_QUEUE_INFO ビュー

JOB_QUEUE_INFO ビューは、ジョブ待ち行列の属性に関する情報を返します。

**権限:** 不要。

**主要カラム:**

| カラム名 | システムカラム名 | データ型 | 説明 |
| --- | --- | --- | --- |
| JOB_QUEUE_NAME | JOBQ | VARCHAR(10) | ジョブ・キューの名前 |
| JOB_QUEUE_LIBRARY | JOBQ_LIB | VARCHAR(10) | ジョブ・キューを含むライブラリー名 |
| JOB_QUEUE_STATUS | STATUS | VARCHAR(8) | ジョブ・キューの状況（HELD、RELEASED） |
| NUMBER_OF_JOBS | JOBS | INTEGER | キュー内のジョブ数 |
| SUBSYSTEM_NAME | SUB_NAME | VARCHAR(10) | このジョブ・キューからジョブを受信できるサブシステムの名前 |
| MAXIMUM_ACTIVE_JOBS | MAX_JOBS | INTEGER | 同時にアクティブにできるジョブの最大数（-1は*NOMAX） |
| ACTIVE_JOBS | ACT_JOBS | INTEGER | 現在アクティブなジョブ数 |
| HELD_JOBS | HELD_JOBS | INTEGER | *HELD 状況の現在のジョブ数 |
| RELEASED_JOBS | RLS_JOBS | INTEGER | *RELEASED 状況の現在のジョブ数 |
| SCHEDULED_JOBS | SCHED_JOBS | INTEGER | *SCHEDULED 状況の現在のジョブ数 |

### 使用例

```sql
-- すべてのジョブ待ち行列情報を表示
SELECT * FROM QSYS2.JOB_QUEUE_INFO;

-- ジョブキューの状況サマリー
SELECT JOB_QUEUE_LIBRARY, JOB_QUEUE_NAME, JOB_QUEUE_STATUS,
       NUMBER_OF_JOBS, ACTIVE_JOBS, HELD_JOBS, RELEASED_JOBS
FROM QSYS2.JOB_QUEUE_INFO
ORDER BY NUMBER_OF_JOBS DESC;

-- アクティブなジョブキューのみを表示
SELECT JOB_QUEUE_NAME, SUBSYSTEM_NAME, 
       ACTIVE_JOBS, MAXIMUM_ACTIVE_JOBS,
       RELEASED_JOBS, HELD_JOBS
FROM QSYS2.JOB_QUEUE_INFO
WHERE SUBSYSTEM_NAME IS NOT NULL
ORDER BY ACTIVE_JOBS DESC;

-- ジョブが多いキューを特定
SELECT JOB_QUEUE_LIBRARY, JOB_QUEUE_NAME,
       NUMBER_OF_JOBS,
       RELEASED_JOBS,
       HELD_JOBS,
       SCHEDULED_JOBS
FROM QSYS2.JOB_QUEUE_INFO
WHERE NUMBER_OF_JOBS > 10
ORDER BY NUMBER_OF_JOBS DESC;

-- 優先順位別のジョブ分布を表示
SELECT JOB_QUEUE_NAME,
       RELEASED_JOBS_PRIORITY_0 AS PRI_0,
       RELEASED_JOBS_PRIORITY_1 AS PRI_1,
       RELEASED_JOBS_PRIORITY_2 AS PRI_2,
       RELEASED_JOBS_PRIORITY_3 AS PRI_3,
       RELEASED_JOBS_PRIORITY_4 AS PRI_4,
       RELEASED_JOBS_PRIORITY_5 AS PRI_5
FROM QSYS2.JOB_QUEUE_INFO
WHERE RELEASED_JOBS > 0
ORDER BY RELEASED_JOBS DESC;
```

## SCHEDULED_JOB_INFO ビュー

SCHEDULED_JOB_INFO ビューは、スケジュールされたジョブに関する情報を返します。

**権限:** 不要。

**主要カラム:**

| カラム名 | データ型 | 説明 |
| --- | --- | --- |
| SCHEDULED_JOB_NAME | VARCHAR(10) | ジョブ・スケジュール・エントリーの名前 |
| SCHEDULED_DATE | DATE | ジョブが投入されるようスケジュールされている日付 |
| SCHEDULED_TIME | TIME | スケジュールされた時刻 |
| FREQUENCY | VARCHAR(8) | ジョブが投入される頻度（*ONCE、*WEEKLY、*MONTHLY、*YEARLY） |
| STATUS | VARCHAR(9) | ジョブ・スケジュール・エントリーの状態（HELD、SAVED、SCHEDULED） |
| NEXT_SUBMISSION_DATE | DATE | ジョブが次に投入されるようスケジュールされている日付 |
| COMMAND_STRING | VARCHAR(512) | 投入されたジョブで実行されるコマンド |

### 使用例

```sql
-- スケジュールされたジョブを表示
SELECT * FROM QSYS2.SCHEDULED_JOB_INFO;

-- 今日実行予定のジョブを表示
SELECT SCHEDULED_JOB_NAME, SCHEDULED_TIME, COMMAND_STRING, STATUS
FROM QSYS2.SCHEDULED_JOB_INFO
WHERE NEXT_SUBMISSION_DATE = CURRENT_DATE
ORDER BY SCHEDULED_TIME;

-- 保留中のスケジュールジョブを表示
SELECT SCHEDULED_JOB_NAME, SCHEDULED_DATE, SCHEDULED_TIME, STATUS
FROM QSYS2.SCHEDULED_JOB_INFO
WHERE STATUS = 'HELD'
ORDER BY SCHEDULED_JOB_NAME;

-- 週次実行のジョブを表示
SELECT SCHEDULED_JOB_NAME, SCHEDULED_DAYS, SCHEDULED_TIME, FREQUENCY
FROM QSYS2.SCHEDULED_JOB_INFO
WHERE FREQUENCY = '*WEEKLY'
ORDER BY SCHEDULED_TIME;
```

## SUBSYSTEM_INFO ビュー

SUBSYSTEM_INFO ビューは、サブシステムに関する情報を返します。

**権限:** 不要。

**主要カラム:**

| カラム名 | データ型 | 説明 |
| --- | --- | --- |
| SUBSYSTEM_DESCRIPTION_LIBRARY | VARCHAR(10) | サブシステム記述が存在するライブラリーの名前 |
| SUBSYSTEM_DESCRIPTION | VARCHAR(10) | サブシステムの名前 |
| STATUS | VARCHAR(10) | サブシステムの状態（ACTIVE、ENDING、INACTIVE、RESTRICTED、STARTING） |
| MAXIMUM_ACTIVE_JOBS | INTEGER | 同時に実行できるジョブの最大数 |
| CURRENT_ACTIVE_JOBS | INTEGER | 現在アクティブなジョブの数 |
| SUBSYSTEM_MONITOR_JOB | VARCHAR(28) | サブシステム・モニター・ジョブの修飾ジョブ名 |

### 使用例

```sql
-- アクティブなサブシステムを表示
SELECT * FROM QSYS2.SUBSYSTEM_INFO
WHERE STATUS = 'ACTIVE';

-- サブシステムの負荷状況を表示
SELECT SUBSYSTEM_DESCRIPTION,
       CURRENT_ACTIVE_JOBS,
       MAXIMUM_ACTIVE_JOBS,
       CASE 
         WHEN MAXIMUM_ACTIVE_JOBS IS NULL THEN 0
         ELSE DECIMAL(CURRENT_ACTIVE_JOBS, 10, 2) / MAXIMUM_ACTIVE_JOBS * 100
       END AS UTILIZATION_PCT
FROM QSYS2.SUBSYSTEM_INFO
WHERE STATUS = 'ACTIVE'
ORDER BY CURRENT_ACTIVE_JOBS DESC;

-- すべてのサブシステムの状態を表示
SELECT SUBSYSTEM_DESCRIPTION, STATUS, CURRENT_ACTIVE_JOBS
FROM QSYS2.SUBSYSTEM_INFO
ORDER BY STATUS, SUBSYSTEM_DESCRIPTION;
```

## ジョブキュー管理のベストプラクティス

### 1. ジョブキューの監視

```sql
-- ジョブキューの健全性チェック
SELECT 
  JOB_QUEUE_LIBRARY || '/' || JOB_QUEUE_NAME AS JOBQ,
  JOB_QUEUE_STATUS,
  NUMBER_OF_JOBS,
  ACTIVE_JOBS,
  RELEASED_JOBS,
  HELD_JOBS,
  CASE 
    WHEN RELEASED_JOBS > 100 THEN 'WARNING'
    WHEN HELD_JOBS > 50 THEN 'ATTENTION'
    ELSE 'OK'
  END AS HEALTH_STATUS
FROM QSYS2.JOB_QUEUE_INFO
WHERE NUMBER_OF_JOBS > 0
ORDER BY NUMBER_OF_JOBS DESC;
```

### 2. ジョブの滞留検出

```sql
-- 長時間待機しているジョブを検出
SELECT 
  J.JOB_NAME,
  J.JOB_USER,
  Q.JOB_QUEUE_NAME,
  J.JOB_ENTERED_SYSTEM_TIME,
  TIMESTAMPDIFF(8, CHAR(CURRENT_TIMESTAMP - J.JOB_ENTERED_SYSTEM_TIME)) AS WAIT_HOURS,
  Q.SUBSYSTEM_NAME,
  Q.ACTIVE_JOBS,
  Q.MAXIMUM_ACTIVE_JOBS
FROM QSYS2.JOB_QUEUE_ENTRIES J
JOIN QSYS2.JOB_QUEUE_INFO Q
  ON J.JOB_QUEUE_NAME = Q.JOB_QUEUE_NAME
  AND J.JOB_QUEUE_LIBRARY = Q.JOB_QUEUE_LIBRARY
WHERE J.JOB_QUEUE_STATUS = 'RELEASED'
  AND TIMESTAMPDIFF(8, CHAR(CURRENT_TIMESTAMP - J.JOB_ENTERED_SYSTEM_TIME)) > 2
ORDER BY WAIT_HOURS DESC;
```

### 3. スケジュールジョブの監視

```sql
-- 今後24時間以内に実行予定のジョブ
SELECT 
  SCHEDULED_JOB_NAME,
  NEXT_SUBMISSION_DATE,
  SCHEDULED_TIME,
  STATUS,
  COMMAND_STRING
FROM QSYS2.SCHEDULED_JOB_INFO
WHERE NEXT_SUBMISSION_DATE BETWEEN CURRENT_DATE AND CURRENT_DATE + 1 DAY
  AND STATUS = 'SCHEDULED'
ORDER BY NEXT_SUBMISSION_DATE, SCHEDULED_TIME;
```

### 4. サブシステムの負荷分析

```sql
-- サブシステム別のジョブ分布
SELECT 
  S.SUBSYSTEM_DESCRIPTION,
  S.CURRENT_ACTIVE_JOBS,
  S.MAXIMUM_ACTIVE_JOBS,
  COUNT(Q.JOB_QUEUE_NAME) AS ATTACHED_JOBQS,
  SUM(Q.NUMBER_OF_JOBS) AS TOTAL_QUEUED_JOBS,
  SUM(Q.RELEASED_JOBS) AS TOTAL_RELEASED_JOBS
FROM QSYS2.SUBSYSTEM_INFO S
LEFT JOIN QSYS2.JOB_QUEUE_INFO Q
  ON S.SUBSYSTEM_DESCRIPTION = Q.SUBSYSTEM_NAME
WHERE S.STATUS = 'ACTIVE'
GROUP BY S.SUBSYSTEM_DESCRIPTION, S.CURRENT_ACTIVE_JOBS, S.MAXIMUM_ACTIVE_JOBS
ORDER BY S.CURRENT_ACTIVE_JOBS DESC;
```
